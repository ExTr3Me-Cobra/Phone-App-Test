# Glow Alerts

Lighting effects for **every** notification: while you use the phone, on the lock screen and on
the Always On Display. Highly customisable, with 31 presets in four groups:

* **Around the screen:** Glow, Line, Pulse, Heartbeat, Comet, Twin comets, Wave, Glitter, Rainbow,
  Flash, Bubbles, Eclipse (round the front camera), Spotlight.
* **Echo:** Echo, Double echo, Echo from the top, Echo from the camera, Echo on the sides.
* **Sides only:** Side glow, pulse, sweep, bounce, wave, rain, flash.
* **Cracking:** Earthquake, Shattered glass, Spiderweb, Lightning crack, Fault lines, Cracked edges.
  Choose *all at once* or *spreading from* top, bottom, left, right, centre, any corner, the
  camera or random; line thickness, detail, flash on impact, edge glow. Every notification gets a
  freshly random crack, and the screen shudders while it spreads.

**Colours:** each app's own colour, one colour, a two-colour gradient or rainbow. The colour picker
has a saturation/brightness square, hue bar, hex entry, ready-made and recent colours, and an
**eyedropper**: open any photo or screenshot, drag over it with a magnifier and use the exact
pixel colour.

**Look:** speed, line thickness, glow amount, brightness, how long it plays, corner curve (or the
screen's real corners). **When:** while using the phone, lock screen, Always On Display, optional
screen wake, silent notifications, per-app on/off. Live preview, full-screen test and a test
notification (also with a 6 s delay for testing while locked).

## Setup
1. Install `GlowAlerts.apk` from Releases (→ *Glow Alerts*).
2. In the app, complete Setup: Notification access, **Glow Alerts Lighting** in Accessibility (if
   greyed out: App info → ⋮ → Allow restricted settings), unrestricted battery, notifications.
3. Turn off Samsung's own edge lighting so you don't get two.

The lighting is drawn by an accessibility service only because that's the one window type Android
allows over the lock screen and AOD; it reads nothing on screen and ignores touches.
