# Viper Vision

A photo gallery and editor for Android (8.0+, 64-bit ARM), built from Fossify Gallery and Image
Toolbox. See [vipervision/README.md](vipervision/README.md) for what's in it and how it's built.

GitHub Actions builds the APK on every push (`.github/workflows/build-vipervision-apk.yml`) and
publishes it as a release named `vipervision-build-N`.
