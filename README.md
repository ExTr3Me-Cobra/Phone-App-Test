# Loadout

A workout logger: build routines (sets, failure sets, rest timers), run them with a timer, log
weight and reps (remembered for next time), and see what improved, how you rank, a muscle
heatmap, and progress graphs for every exercise.

- 739 exercises: names, equipment and muscles from Free Exercise DB (github.com/yuhonas/free-exercise-db, Unlicense;
  its directions are not used), plus your own. Directions: written for Loadout, some adapted from wger.de contributors
  (CC BY-SA / CC0, listed in tools/exercise_text/credits.json).
- Exercise pictures: a muscle chart by default; add your own picture, or make one with OpenAI
  (your API key, set in Profile → Settings).
- Ranks compare you with people who lift of your sex, body weight and age, using standards built from published
  research and open lifting data (tools/standards: sources, inputs and the build script).

Install: open the latest **loadout-N** release and tap **Loadout.apk**.
