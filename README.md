# Iron Log

A workout logger: build routines (sets, failure sets, rest timers), run them with a timer, log
weight and reps (remembered for next time), and see what improved, how you rank, a muscle
heatmap, and progress graphs for every exercise.

- 876 exercises from the public-domain Free Exercise DB (github.com/yuhonas/free-exercise-db),
  plus your own.
- Exercise pictures: a muscle chart by default; add your own picture, or make one with OpenAI
  (your API key, set in Profile → Settings).
- Rankings are estimates from published strength standards (body weight, sex, age).

Install: open the latest **iron-log-N** release and tap **IronLog.apk**.
